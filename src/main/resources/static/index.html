BinGo Map의 주요 기능

1. 쓰레기통 스마트 맵

현재 위치 주변의 공공 쓰레기통,
편의점, 자판기 수거함 위치를
실시간으로 확인할 수 있습니다.

2. 테이크아웃 맛집 추천

쓰레기통 반경 500m 내
길거리 음식 맛집을 검색하고,
상세 정보와 리뷰를 확인하세요.

3. 최적 루트 안내

맛집에서 쓰레기통까지의
최단 경로를 안내하여
더 편리한 여행을 도와드립니다.

4. 커뮤니티

쓰레기통 제보, 리뷰 작성,
댓글로 소통을 통해
정보를 함께 나눠요.
